
# ENIXORA – Business Website

A modern, responsive business website developed for ENIXORA, focusing on clean design, user-friendly navigation, and a professional user experience.

## 🌐 Live Website

[Visit ENIXORA](https://enixora.com/)

## 📌 Project Overview

ENIXORA is a business website designed to present services and business information through a modern and visually appealing web interface.

The main focus of this project was to create a clean layout, maintain visual consistency, and provide a smooth browsing experience across different screen sizes.

## ✨ Key Features

- Modern and professional website design
- Responsive layouts for different screen sizes
- Clean and user-friendly navigation
- Visually appealing content presentation
- Consistent typography, spacing, and layout
- User-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 My Contribution

I worked on the frontend development of the website, focusing on:

- Creating website layouts and page structures
- Styling components using CSS
- Implementing interactive elements using JavaScript
- Improving responsiveness and visual consistency
- Focusing on usability and user experience
